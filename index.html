Aqui está a solução completa consolidada em um único arquivo HTML (askesis-md.html). Este arquivo contém toda a lógica, estilos, scripts, ícones (SVG embutidos) e o manifesto PWA necessário para funcionar como um aplicativo instalável em qualquer dispositivo (Desktop, Android, iOS). Ele inclui: Múltiplas abas com persistência local. Parser Markdown robusto (usando a biblioteca marked via CDN, com fallback se offline). Realce de sintaxe no editor (simulado com overlay de cores). Exportação completa: MD, HTML, PDF, FODT, RTF + Estilos personalizados "Askemata". Atalhos de teclado (Ctrl+S, Ctrl+W, Ctrl+Tab, etc.). Sistema de Temas (Claro/Escuro). PWA Manifest embutido para instalação. Sincronização Local (salva automaticamente no localStorage). Instruções Copie o código abaixo. Salve como askesis-md.html. Abra no navegador. Para instalar: Clique no ícone de "+" no endereço do navegador (Desktop) ou "Adicionar à Tela Inicial" (Mobile). Askesis-MD Editor
